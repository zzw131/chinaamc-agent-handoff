# P0002 首页固定素材

请先读 [素材清单](asset-manifest.json)。清单记录每个 PNG 的用途、原稿位置、显示尺寸和来源。所有坐标以 750 × 3540 的首页原稿为准。在 375 px 宽的视口按清单的显示尺寸排版。

| 素材 | 文件位置 | 用法 |
| --- | --- | --- |
| 首页经理形象 | [manager-home@4x.png](characters/manager-home@4x.png) | Figma 图层原样 4× 导出，实存 301 × 419 px。用透明 PNG 原比例显示。 |
| 全部基金、我的自选、活期通、亲子账户、积分兑好礼 | [icons/shortcuts](icons/shortcuts/) | 每张 280 × 280 px，基准显示为 35 × 35 CSS px。PNG 已含白色圆角底板。入口文字用真实文本。 |
| 消息、搜索、信息精选标记 | [icons/header](icons/header/) | 消息图含圆底与红点。搜索图仅含放大镜。 |
| 底部导航的首页选中态及四个未选中态 | [icons/navbar](icons/navbar/) | 使用清单对应文件。基准显示为 20 × 20 CSS px，文字另排。 |
| 热销榜、收益榜、定投榜 | [icons/ranking](icons/ranking/) | 使用全徽章 PNG，按清单保留图层内部留白。 |

实现时将这些文件复制到项目静态资源目录，保留透明通道、宽高比和原色。画面出现同名元素时直接引用指定路径。禁止用图标库、Emoji、文字或重新生成的图替代这些资产。遇到无法读取的文件，报告清单里的相对路径。界面布局以 [P0002 首页](../../references/screens/home-and-follow/P0002-home.png) 为准。

四个快捷入口使用内置 ImageGen 修复。提示要求只提升原位图的清晰度，保持白色底板、原图案、比例、红色和内部留白。活期通以原稿位图提取版交付，保留原标字形。底部导航、精选区标记及榜单徽章从 Figma 图层直接导出。
