**尺寸与布局【实测】**
- 状态栏 y = 0–65 px（65 px = 24.76 dp）。

**文字层级【实测 bounds + 估算字号】**

**间距【实测】**
- 头像 right 190 → 昵称 left 222，间距 32 px。
- 昵称 bottom 264 → 欢迎语 top 285，间距 21 px。

**变体【观察】**

4. 登录页（P0004）为 FLAG_SECURE，仅 UI 层级，无可见截图。

**交互行为【部分已验证】**
- 首页搜索框点击 → P0020（已验证，热区 `[64,152][1006,236]`）。
- 「我的」页设置/客服/消息图标：入口存在【实测】，具体跳转目标未逐一验证【未验证】。

**状态【观察 + 推测】**
- 默认态【观察】。
- 键盘弹起时输入区上移【推测】，位移量未逐帧测量（见 `PAGE_SPEC.md`）。

**可配置内容【推测】**
