# DATA_RULES.md — 数据取证、Mock 与使用规则

> 适用对象：`07_mock_data/data_schema.json`、`07_mock_data/mock_data.json`，以及引用本目录数据的页面还原 / 演示 / 测试代码。
> 编写日期：2026-11-27。
> 核心原则：**真实观察与 mock 必须可区分；不得把 mock 冒充真实数据；不得虚构真实接口、业务规则、账户信息或法律条款。**

---

## 1. 数据分级

| 级别 | 标识 | 定义 | 本工程中的载体 |
|---|---|---|---|
| L1 实测 | `observed` / `measured` | 来自真实截图、uiautomator dump、adb 环境读取，可回溯到具体文件与坐标 | 页面规格、截图、UI dump、本文档「观察数据清单」 |
| L2 采样 | `sampled` | 对原始 PNG 区域做像素统计得到的近似颜色值，可复现但不是官方色值 | `design_tokens.json`、`DESIGN_SYSTEM.md` 附录 A |
| L3 脱敏 | `desensitized` | 截图本身已用 `******` / `****` 遮蔽，或本工程置为 `null` | `mock_data.json` 的 `userAccount` 区块 |
| L4 Mock | `mock` / `MOCK_` 前缀 | 为演示、占位、结构说明而编造的示例值 | `mock_data.json` 的 `fundList`、`searchResult.items`、`agreements.content` 等 |
| L5 未采集 | `null` / `unverified` | 被登录、FLAG_SECURE、实名、风测或安全边界阻断；无数据 | 账户、持仓、交易、银行卡、协议正文等 |

> **L4 与 L5 都不可作为真实业务数据使用。** 区别是：L4 有示例值用于演示，L5 连示例值都没有。

## 4. 脱敏与隐私规则（L3 / L5）

1. 本工程**无真实账号、无真实身份、无真实资金数据**。采集前已 `pm clear`，全程未登录。
2. `userAccount` 中 `totalAssets`、`points`、`weeklyReport` 的 `******` / `****` 是**截图自身的脱敏显示**，不是被打码的真实数值；不得反推、不得填充。
3. `accountId`、`identity`、`bankCards`、`holdings`、`transactions` 固定为 `null`。**禁止编造身份证号、手机号、银行卡号、资金账号、姓名、头像等个人信息。**
4. 页面中出现的用户头像（底部导航第 4 槽位、「我的」页头像）仅为 UI 占位/系统图像，不代表任何真实用户。
5. 任何后续开发若需账户数据，必须接入用户授权的真实来源，不得使用本目录 mock 数据冒充。

## 5. 后续开发使用规则

### 5.1 允许的用法

- 用于**视觉还原、布局走查、交互演示、自动化测试夹具**。
- 用于生成 UI 占位内容与截图比对基线。
- 引用 `design_tokens.json` 中 `source: measured` / `sampled` 的色值与尺寸做高保真还原。
- 引用 `source: estimated` 的值作为**起始参考**，并在实现中标注需人工核对。

### 5.2 禁止的用法（红线）

1. **禁止虚构真实接口**：不得编造 api 域名、路径、请求参数、返回结构、鉴权方式，或声称某数据来自真实服务端。
2. **禁止虚构业务规则**：不得编造交易规则、费率规则、风险测评规则、申购/赎回逻辑、收益计算方式；采集在产生真实业务影响前已停止。
3. **禁止把 mock 当真实数据**：界面上若使用 mock 数值，应在演示环境显式标注 `mock` / `示例`，不得让用户误认为是实时行情或真实资产。
4. **禁止把估算当实测**：字号、圆角、阴影、透明度、风险等级色等 `estimated` 项，不得在验收文档中写成「已实测还原」。
5. **禁止把采样色当官方品牌色**：`design_tokens.json` 的 hex 来自截图采样，未经官方确认；对外品牌物料必须人工取样核对。
6. **禁止补全未验证交互**：登录拦截后的流程、基金详情、持仓、交易、客服等未验证项，按合理默认实现时必须显式标注「未验证 / 推测」。
7. **禁止编造协议正文**：协议文本须由真实 legal 来源提供。
8. **禁止用本目录数据做真实交易或合规展示**。

### 5.3 行情数据的时效性

- `mock_data.json` 中的指数点位、涨跌幅、PE/PB、更新时间是 **2026-11-27 的静态快照**，仅用于视觉与结构演示。
- 不得作为实时行情、投资建议或历史数据引用；真实行情须接入有资质的行情源。

## 6. 更新与维护

1. 若后续补采（登录后页面、横屏态、H5 内部元素），新增观察值应写入对应 `PAGE_SPEC.md` 与本页面清单，并同步 `data_schema.json` 字段来源。
2. 在 `mock_data.json` 中新增示例值时必须使用 `MOCK_` 前缀或 `mock` 标识；新增账户类字段一律 `null`。
3. 修改 `design_tokens.json` 前，先确认 `source` 标记与实际取证方式一致；不得把 `estimated` 改为 `measured` 而无新证据。
4. 发现本文档「已知观察冲突」出现新证据时，更新冲突表并保留历史记录，不直接覆盖原观察。
