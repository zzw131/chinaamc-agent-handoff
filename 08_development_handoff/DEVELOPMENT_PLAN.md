## 阶段 1：基础框架

**范围**：无独立页面，搭建工程骨架。

- 建立页面注册表：以 `01_architecture/routes.json` 的 21 条记录为准。
- 建立路由与导航：底部导航 5 tab（首页 / 指数行情 / 资产 / 客服图标 / 我的），其中「资产」tab 走登录拦截。
- 建立 WebView 容器：承载 P0007 / P0012 / P0013 / P0022 / P0030 / P0037。
- 建立登录拦截中间件：命中 `blocked_flows.md` 中登录类入口时统一跳 `P0004`。
- 建立 mock 数据层：读取 `PAGE_SPEC.md` 第 7 节结构与 `07_mock_data/`（若存在）。
- 建立组件基础：C001–C010 的壳组件与 variant 机制。
- 建立验收基线：1080×2400 渲染与截图比对脚本。

**依赖**：无。**交付**：可运行空壳 + 路由表 + 组件表 + mock 表。

## 阶段 5：核心业务流程

| 流程 | 名称 | 覆盖页面 | 验收重点 |
|---|---|---|---|
| F001 | 首次启动与协议同意 | P0001 → P0002 | 同意/跳过主链路；分支标注未验证 |
| F002 | 未登录浏览触发登录拦截 | P0002/P0005/P0007/P0021 → P0004 | 6 个拦截点全部命中 |
| F003 | 登录 → 注册/找回密码分支 | P0004/P0033/P0035 | 协议弹窗分支；禁止假定登录成功 |
| F004 | 搜索 → 结果 → 指数详情 | P0002/P0003 → P0020 → P0021 → P0022 | 主链路已验证，全部可走通 |
| F005 | 设置 → 协议列表 → 协议详情 H5 | P0005 → P0023 → P0029 → P0030 | ID 冲突按约定处理 |
| F006 | 首页 Banner → 活动 H5 | P0002 → P0037 | 目标为 P0037 而非会员中心 |
| F007 | 指数行情 → 指数详情 | P0002 → P0003 → P0022 | 热力图与列表项两个入口 |

**金融业务**：仅实现「点击 → 登录拦截 → 提示未开通」的模拟闭环，不实现下单、金额输入、份额确认、风测提交、绑卡。
